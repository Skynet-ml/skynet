Skynet — це Optimize Anything: кожен запуск оптимізує репозиторій. Рушій пропонує нові версії репозиторію, ваш оцінювач оцінює кожну версію, а Skynet зберігає найкращу.

## Спільний контракт

Кожен запуск має репозиторій і оцінювач. Оцінювач — це функція Python, яка отримує шлях до однієї версії репозиторію й один кейс.

```python tab="scorer.py"
import importlib.util


def score(repo_path, case):
    spec = importlib.util.spec_from_file_location("serve", f"{repo_path}/serve.py")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    output = module.serve(case["input"])
    ok = output == case["expected"]
    return (1.0 if ok else 0.0), {"feedback": "Match." if ok else "No match."}
```

- `repo_path` — це папка однієї версії репозиторію після виконання команди налаштування.
- `case` — це словник. `case["input"]` містить вхідні поля одного кейсу. `case["expected"]` містить очікуване значення або `None`, якщо кейс його не має.
- `score` повертає пару: число й словник із рядком `"feedback"`.

Репозиторій має в корені файл `serve.py` з `def serve(input)`. Оцінювач може його викликати, а Skynet використовує його, щоб обслуговувати найкращу версію після запуску.

> [!NOTE]
> Агент програмування, який пише версії, не бачить вихідного коду оцінювача, очікуваних значень і секретів запуску.

Повний контракт оцінювача описано в розділі [Метрики й оцінювачі](/docs/concepts/scorers).

## Виклики моделей з вашого коду

Код вашого репозиторію й ваш оцінювач можуть викликати модель через шлюз моделей Skynet. Пісочниця надає ендпоінт, сумісний з OpenAI, у змінних середовища:

| Змінна               | Що вона містить                                                  |
| -------------------- | ---------------------------------------------------------------- |
| `OPENAI_BASE_URL`    | URL шлюзу. `APP_GATEWAY_URL` містить те саме значення.           |
| `APP_API_KEY`        | Токен лише для цього запуску. Це не ключ провайдера.             |
| `APP_MODEL`          | Назва моделі, яку треба надсилати. Це модель оцінювача запуску.  |
| `ANTHROPIC_BASE_URL` | URL шлюзу для SDK Anthropic.                                     |

```python tab="pipeline.py"
import os

from openai import OpenAI

client = OpenAI(base_url=os.environ["OPENAI_BASE_URL"], api_key=os.environ["APP_API_KEY"])


def label(message):
    response = client.chat.completions.create(
        model=os.environ["APP_MODEL"],
        messages=[{"role": "user", "content": f"Label as billing, bug or other: {message}"}],
    )
    return response.choices[0].message.content
```

- Виклики на ключах Skynet враховуються в бюджеті запуску.
- З вашим власним ключем (BYOK) виклик іде на ключ вашого провайдера. Skynet не стягує плату за модель.
- Шлюз відхиляє запити до будь-якої іншої моделі.
- Секрети запуску потрапляють у ваш код і ваш оцінювач як змінні середовища. Назва змінної — це назва секрету. Skynet приховує значення секретів у виводі.

Пісочниця не має іншого доступу до мережі.

## Рушії

Кожен рушій працює з репозиторіями:

- **Auto** — типовий вибір. Він пробує кілька рушіїв, а потім продовжує GEPA з найкращої версії.
- **GEPA** розвиває версії через рефлексію й підтримує фронт Парето.
- **Best-of-N** просить модель рефлексії про незалежні пропозиції й зберігає найкращу.
- **AutoResearch**, **Meta-Harness**, **AutoSaddler** і **ShinkaEvolve** використовують агента-програміста, щоб пропонувати версії.

Рушії змінюють лише файли в дозволених вами шляхах. Кожен рушій і його налаштування описано в розділі [Рушії](/docs/concepts/engines).

## Auto

**Auto** — типовий вибір у майстрі для кожного запуску.

1. Auto досліджує п’ятьма рушіями: GEPA, AutoResearch, Meta-Harness, AutoSaddler і ShinkaEvolve.
2. Він обирає найкращу версію, яку вони знайшли.
3. Він продовжує GEPA з цієї версії, доки не вичерпається бюджет.

Auto читає текст відгуку вашого оцінювача.

## Звідки береться початкова версія

| Ваша ситуація                       | Що використати                                                                              |
| ----------------------------------- | ------------------------------------------------------------------------------------------- |
| У вас є код у репозиторії GitHub    | **Використати репозиторій**. Початок — це код у гілці або коміті, які ви обираєте.          |
| У вас є лише завдання й дані        | **Створити новий репозиторій**. Skynet пише перше рішення. Це і є початок.                  |

> [!WARNING]
> GEPA і Auto навчаються на тексті відгуку. Якщо ваш відгук завжди той самий рядок, ці оптимізатори мають менше інформації для роботи.
