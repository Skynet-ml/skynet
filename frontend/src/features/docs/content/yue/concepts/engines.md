引擎係提出你倉庫新版本嘅搜尋方法。Skynet 有六個原生引擎同埋 **Auto**。每個引擎都處理倉庫。呢頁講每個做乜、幾時揀佢，同埋有咩設定。

如果你唔知道邊個引擎適合你嘅任務，請先睇 [最佳化點樣運作](/docs/concepts/optimization)。

## 快速比較

| 引擎         | 編程代理設定               | 最多迭代次數設定 |
| ------------ | -------------------------- | ---------------- |
| Auto         | 冇                         | 冇               |
| GEPA         | 冇                         | 冇               |
| Best-of-N    | 冇                         | 冇               |
| AutoResearch | 有                         | 冇               |
| Meta-Harness | 有                         | 有               |
| AutoSaddler  | 有                         | 有               |
| ShinkaEvolve | 冇。佢有自己嘅編輯器設定。 | 有               |

精靈會將 GEPA 同 Auto 標示為會用你評分器回饋文字嘅優化器。

## Auto

Auto 係每次運行嘅預設選擇。佢分兩個階段運作：

1. 佢用 GEPA、AutoResearch、Meta-Harness、AutoSaddler 同 ShinkaEvolve 探索。
2. 佢由探索搵到最好嗰個版本繼續行 GEPA。

**幾時揀佢**：你唔知道邊個引擎適合。呢度係最好嘅起點。

## GEPA

「用版本嘅 Pareto 前沿做反思式演化。」反思模型會讀每個案例嘅分數同回饋，然後寫一個更好嘅版本。GEPA 會保留一個版本前沿，入面每個版本都喺某啲案例上係最好。

**幾時揀佢**：你嘅評分器畀出具體回饋，而你想要一個強勁嘅單一引擎。

## Best-of-N

「由反思模型提出獨立提案；保留最好嗰個。」每個提案都同其他提案互相獨立。Skynet 會喺驗證案例上為排頭嘅提案重新評分。

**幾時揀佢**：你想要一個簡單嘅基準，同其他引擎比較。

## AutoResearch

一個編程代理會進行一輪輪研究。佢會修改、評分，保留有幫助嘅改動，直到預算用完。

**幾時揀佢**：一個好嘅改動需要幾個步驟嘅調查。

## Meta-Harness

一個編程代理每輪迭代提出一批候選。佢會用晒所有候選同分數嘅完整歷史。

**幾時揀佢**：你想要一個會由之前所有嘗試嘅歷史學習嘅 agent。用 **每輪候選數** 設定每批嘅大小。

## AutoSaddler

一個編程代理會讀你評分器嘅回饋，然後修補個版本。Skynet 只會保留經新一次評分器運行確認過嘅修補。

**幾時揀佢**：你嘅評分器回饋指向清晰、局部嘅缺陷。

## ShinkaEvolve

「喺平行島嶼上演化好多個版本，並學習邊啲模型最能夠改良佢哋。」佢係對一群候選做嘅演化搜尋，突變同交叉都由模型寫出嚟。

**幾時揀佢**：你想要廣泛探索，而且你有較大嘅預算。

## 設定

### 預算

| 設定                 | 預設 | 範圍                                                        |
| -------------------- | ---- | ----------------------------------------------------------- |
| 評分器最多運行次數   | 200  | 1 至 100000                                 |
| 停止分數             | 關   | 0 或以上                                                    |
| 最多迭代次數         | 關   | 1 至 1000。只限 Meta-Harness、AutoSaddler 同 ShinkaEvolve。 |

一次評分器運行，就係喺一個案例上呼叫一次你嘅評分器。最後為起始版本同勝出者重新評分，唔會計入 **評分器最多運行次數**。

### 編程代理設定

呢啲設定適用於 AutoResearch、Meta-Harness 同 AutoSaddler。

| 設定                       | 預設  | 範圍                                             |
| -------------------------- | ----- | ------------------------------------------------ |
| 編程代理                   | Codex | Pi、Codex、OpenCode、OpenCode V2、Prime Agent、Aider、OpenHands、OpenHands SDK、Antigravity SDK、Goose、Hermes Agent、eve、DeerFlow、Cline、Code Puppy、自訂指令       |
| 每輪候選數                 | 3     | 1 至 8。 |
| 每個候選最多工具呼叫次數   | 100   | 1 至 1000                                        |

### ShinkaEvolve 設定

| 設定                         | 預設                                               |
| ---------------------------- | -------------------------------------------------- |
| 新版本點樣寫出嚟             | 單次模型呼叫。另一個選項係「編碼代理（Pi）」。     |
| 島嶼                         | 2（1 至 8）                                        |
| 遷移間隔                     | 10                                                 |
| 父代選擇                     | 加權。其他選項：冪律、束搜尋。                     |
| 差異編輯 / 完整重寫 / 交叉   | 60% / 30% / 10%。加埋一定要等於 100%。             |
| 存檔大小                     | 40                                                 |
| 並行評估                     | 2                                                  |
| 並行提案                     | 2                                                  |
