Agent 面板係 Skynet 入面嘅一個對話助手。佢可以讀取你嘅運行、數據集同結餘，亦可以代你做嘢，例如將一個運行改名或者取消佢。你控制邊啲操作需要你批准。

## 打開面板

面板會喺應用程式側邊打開。當你將佢縮細，畫面上會留低一粒寫住 **開啟 Agent** 嘅膠囊掣。撳嗰粒掣，就可以再打開面板。

撳 **我可以幫你做咩**，睇 Agent 嘅工具清單。

### 對話

- **新對話** 會開始一個空白對話。
- **過往對話** 會列出你以前嘅對話。你可以搜尋、置頂、重新命名同刪除佢哋。

### 發送訊息

輸入你嘅訊息，再按 Enter。你亦可以撳 **語音輸入**，講出你嘅訊息。

Agent 做緊嘢嗰陣，你仍然可以用輸入框：

- 支援引導時，**Enter** 會引導目前嘅工作，Agent 喺下一步讀取訊息。**Tab** 會將新一輪對話加入佇列。唔支援引導時，Enter 都會加入佇列。
- 喺 **待處理訊息** 區，你可以編輯、刪除同拖曳訊息嚟改變次序。**引導** 可用時，可以將佇列訊息送入目前嘅工作。
- 標記為 **未確認** 嘅訊息可能已經送到 Agent。冇對話運行時，請用嗰條訊息嘅選單明確傳送。你隨時可以編輯或者刪除佢。佇列入面其他訊息可以先繼續。
- **停止** 會停止目前一輪，同埋暫停佇列。未讀嘅引導訊息會返到待處理區，唔會自動開始。輸入框入面嘅 **Esc** 都一樣。佢會先關閉輸入框嘅建議或者選單，用 IME 組字嗰陣唔會停止。
- 冇對話運行而佇列暫停時，**即刻傳送** 會傳送第一條訊息，其餘會按次序繼續。正常完成一輪都會開始下一條訊息。
- 登入後，文件助手宣布安全步驟邊界之後，**Enter** 就會引導目前工作。訊息會喺下一個原有嘅模型步驟讀取。**Tab** 永遠加入佇列。宣布之前、未登入時，同已發佈程式嘅受保護對話入面，Enter 同 Tab 都會加入佇列。遇到請求次數限制時，文件助手會暫停剩低嘅訊息。

## Agent 可以做乜

Agent 可以讀取：

- 你嘅運行、佢哋嘅記錄同測試結果。
- 分析數據同你嘅錢包結餘。
- 你資料庫入面嘅數據集，同埋公開搜尋結果。
- 你嘅標註工作階段（唯讀）。
- 範例數據集、引擎目錄同優化器目錄。

Agent 亦可以做操作。安全操作包括：

- 將運行改名同置頂，同埋一次過置頂好多個運行。
- 暫停運行。
- 編輯同驗證運行嘅程式碼。
- 分析數據集概況，同設定佢嘅欄位角色。
- 搵可用嘅模型。
- 更新提交精靈同你嘅偏好設定。
- 準備一個範例數據集。
- 建立資料夾。

破壞性操作包括：

- 刪除一個或者多個運行。
- 提交、取消、複製、重試、繼續或者重新執行一個運行，同埋取消多個運行。
- 刪除、移動或者更新資料夾，同埋喺資料夾之間移動運行。

> [!NOTE]
> 網頁工具（搜尋、讀取網址、爬取網站）只有喺伺服器設定咗網頁搜尋金鑰嘅時候先用得。如果你睇唔到佢哋，即係你嘅 Skynet 實例冇提供。

## 信任模式

信任模式設定邊啲操作需要你批准。撳輸入框入面嘅信任切換掣去改。切換掣會喺三個模式之間輪流轉。

| 模式           | 說明                             | 安全操作   | 破壞性操作 |
| -------------- | -------------------------------- | ---------- | ---------- |
| **每次詢問**   | 每個操作之前都會要求確認。       | 需要批准   | 需要批准   |
| **自動**       | 安全操作唔使確認就會執行。       | 即刻執行   | 需要批准   |
| **無限制**     | 所有操作都唔使確認就會執行。     | 即刻執行   | 即刻執行   |

預設模式係 **每次詢問**。唯讀工具永遠唔需要批准。

> [!WARNING]
> 喺 **無限制** 模式，Agent 可以唔經批准就刪除運行或者提交付費運行。只有喺你信任個任務嘅時候先用呢個模式。

### 設定預設模式

1. 打開 **設定**。
2. 打開 **Agent 面板** 分頁。
3. 喺 **Agent 信任級別** 下面，揀 **每次先詢問**、**淨係自動執行安全操作** 或者 **無需預先核准**。

### 批准操作

當一個操作需要批准，面板會顯示一張批准卡。卡上面有一個確認該操作嘅掣，同埋 **取消**。撳 **顯示技術詳細資料**，睇確實嘅工具呼叫。

如果你 15 分鐘之內冇回應，Agent 會當個操作被拒絕。

## 附加檔案

你可以喺訊息附加檔案。每個檔案最大 20 MB。每次只可以附加一個數據集。

想經 Agent 上載數據集：

1. 附加一個 CSV、JSON 或者 Excel 檔案。
2. 檢查上載卡。佢會顯示檔案嘅欄位。
3. 喺卡上面設定欄位角色，然後確認。

如果 Agent 讀唔到檔案，卡會顯示「讀取唔到檔案。請使用 CSV、JSON 或 XLSX 檔案。」

檔案規則請睇 [準備數據集](/docs/guides/datasets)。

## 揀模型

輸入框入面嘅模型選單有以下幾組：

- **Auto** 畀 Skynet 揀模型。
- **Skynet 額度** 用雲端模型，費用由你嘅結餘支付。
- **用自己嘅金鑰** 經你自己嘅供應商金鑰用模型。

有啲模型可以畀你設定推理強度。級別有 **無**、**極低**、**低**、**中**、**高**、**超高** 同 **最高**。**預設** 會用模型嘅預設級別。

想為新對話設定預設模型，打開 **設定** > **Agent 面板** > **預設模型**。

### 費用

用 Skynet 額度嘅 Agent 對話會用你嘅結餘。如果你嘅結餘係零，面板會顯示「你嘅餘額已經用晒。請增值，繼續同助理傾偈。」價錢請睇 [收費](/docs/concepts/billing)。

## 小貼士

> [!TIP]
> 改一個運行之前，先叫 Agent 解釋佢。例如：「點解運行 42 嘅分數低過運行 41？」

> [!TIP]
> 試新類型嘅請求時，用 **每次詢問** 模式。當你知道 Agent 會做乜，就轉去 **自動**。
