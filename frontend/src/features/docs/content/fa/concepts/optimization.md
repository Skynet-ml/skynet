Skynet همان Optimize Anything است: هر اجرا یک مخزن را بهینه می‌کند. یک موتور نسخه‌های تازه‌ای از مخزن پیشنهاد می‌کند، امتیازدهندهٔ شما به هر نسخه امتیاز می‌دهد و Skynet بهترین نسخه را نگه می‌دارد.

## قرارداد مشترک

هر اجرا یک مخزن و یک امتیازدهنده دارد. امتیازدهنده یک تابع Python است که مسیر یک نسخه از مخزن و یک مورد را می‌گیرد.

```python tab="scorer.py"
import importlib.util


def score(repo_path, case):
    spec = importlib.util.spec_from_file_location("serve", f"{repo_path}/serve.py")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    output = module.serve(case["input"])
    ok = output == case["expected"]
    return (1.0 if ok else 0.0), {"feedback": "Match." if ok else "No match."}
```

- `repo_path` پوشهٔ یک نسخه از مخزن است، پس از اجرای دستور راه‌اندازی.
- `case` یک dict است. `case["input"]` فیلدهای ورودی یک مورد را نگه می‌دارد. `case["expected"]` مقدار مورد انتظار را نگه می‌دارد، یا وقتی مورد مقداری ندارد `None` است.
- `score` یک جفت برمی‌گرداند: یک عدد، و یک dict با یک رشتهٔ `"feedback"`.

مخزن در ریشهٔ خود یک فایل `serve.py` با `def serve(input)` دارد. امتیازدهنده می‌تواند آن را فراخوانی کند، و Skynet پس از اجرا با آن بهترین نسخه را سرویس می‌دهد.

> [!NOTE]
> عامل کدنویسی که نسخه‌ها را می‌نویسد نمی‌تواند کد منبع امتیازدهنده، مقدارهای مورد انتظار یا رازهای اجرا را ببیند.

برای قرارداد کامل امتیازدهنده، [معیارها و امتیازدهنده‌ها](/docs/concepts/scorers) را بخوانید.

## فراخوانی‌های مدل از کد شما

کد مخزن و امتیازدهندهٔ شما می‌توانند از طریق دروازهٔ مدل Skynet یک مدل را فراخوانی کنند. محیط اجرای ایزوله یک نقطهٔ پایانی سازگار با OpenAI را در متغیرهای محیطی می‌دهد:

| متغیر                | چه چیزی را نگه می‌دارد                                     |
| -------------------- | ---------------------------------------------------------- |
| `OPENAI_BASE_URL`    | نشانی دروازه. `APP_GATEWAY_URL` همان مقدار را نگه می‌دارد. |
| `APP_API_KEY`        | یک توکن فقط برای این اجرا. کلید ارائه‌دهنده نیست.           |
| `APP_MODEL`          | نام مدلی که باید بفرستید. این مدل امتیازدهندهٔ اجراست.      |
| `ANTHROPIC_BASE_URL` | نشانی دروازه برای SDKهای Anthropic.                         |

```python tab="pipeline.py"
import os

from openai import OpenAI

client = OpenAI(base_url=os.environ["OPENAI_BASE_URL"], api_key=os.environ["APP_API_KEY"])


def label(message):
    response = client.chat.completions.create(
        model=os.environ["APP_MODEL"],
        messages=[{"role": "user", "content": f"Label as billing, bug or other: {message}"}],
    )
    return response.choices[0].message.content
```

- فراخوانی‌هایی که از کلیدهای Skynet استفاده می‌کنند از بودجهٔ اجرا اندازه‌گیری و کسر می‌شوند.
- با کلید خودتان (BYOK)، فراخوانی به کلید ارائه‌دهندهٔ شما می‌رود. Skynet هیچ کارمزد مدلی دریافت نمی‌کند.
- دروازه درخواست‌ها برای هر مدل دیگری را رد می‌کند.
- رازهای اجرا به‌صورت متغیرهای محیطی به کد و امتیازدهندهٔ شما می‌رسند. نام متغیر همان نام راز است. Skynet مقدار رازها را در خروجی پنهان می‌کند.

محیط اجرای ایزوله هیچ دسترسی شبکهٔ دیگری ندارد.

## موتورها

همهٔ موتورها روی مخزن‌ها کار می‌کنند:

- **Auto** پیش‌فرض است. چند موتور را امتحان می‌کند، سپس GEPA را از بهترین نسخه ادامه می‌دهد.
- **GEPA** نسخه‌ها را با بازاندیشی تکامل می‌دهد و یک جبههٔ پارتو نگه می‌دارد.
- **Best-of-N** از مدل بازاندیشی پیشنهادهای مستقل می‌خواهد و بهترین را نگه می‌دارد.
- **AutoResearch**، **Meta-Harness**، **AutoSaddler** و **ShinkaEvolve** برای پیشنهاد نسخه‌ها از یک عامل کدنویسی استفاده می‌کنند.

موتورها فقط فایل‌های مسیرهایی را تغییر می‌دهند که شما اجازه می‌دهید. برای هر موتور و تنظیمات آن، [موتورها](/docs/concepts/engines) را بخوانید.

## Auto

**Auto** انتخاب پیش‌فرض در ویزارد است، برای همهٔ اجراها.

1. ‏Auto با پنج موتور کاوش می‌کند: GEPA، AutoResearch، Meta-Harness، AutoSaddler و ShinkaEvolve.
2. بهترین نسخه‌ای را که آن‌ها پیدا کردند انتخاب می‌کند.
3. GEPA را از آن نسخه ادامه می‌دهد تا بودجه تمام شود.

‏Auto متن بازخورد امتیازدهندهٔ شما را می‌خواند.

## نسخهٔ شروع از کجا می‌آید

| وضعیت شما                        | استفاده کنید                                                                          |
| -------------------------------- | ------------------------------------------------------------------------------------- |
| کدی در یک مخزن GitHub دارید       | **استفاده از یک مخزن**. کد در شاخه یا commit که انتخاب می‌کنید نقطهٔ شروع است.          |
| فقط یک کار و داده دارید            | **ساخت مخزن جدید**. Skynet یک راه‌حل اول می‌نویسد. همان نقطهٔ شروع است.             |

> [!WARNING]
> GEPA و Auto از متن بازخورد یاد می‌گیرند. اگر بازخورد شما همیشه همان رشته باشد، این بهینه‌سازها اطلاعات کمتری برای کار دارند.
