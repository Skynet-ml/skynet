صفحهٔ اجرا پیشرفت و نتایج یک اجرا را نشان می‌دهد. این راهنما زبانه‌های صفحهٔ اجرا، امتیازها و روش خروجی گرفتن از بهترین نسخه یا ارائهٔ آن را توضیح می‌دهد.

## زبانه‌های صفحهٔ اجرا

صفحهٔ اجرا فقط زبانه‌هایی را نشان می‌دهد که به آن اجرا مربوط هستند. برخی زبانه‌ها به وضعیت و سطح تجربهٔ شما بستگی دارند.

| زبانه                   | چه زمانی نمایش داده می‌شود                        | محتوای آن                                                         |
| ----------------------- | ------------------------------------------------- | ----------------------------------------------------------------- |
| **نمای کلی**            | همیشه                                             | پیشرفت، امتیازها و تاریخچهٔ امتیاز                                 |
| **کاربرد**              | اجرای موفقی که مخزنش یک فایل `serve.py` دارد       | فرمی برای فراخوانی بهترین نسخه، و کد یکپارچه‌سازی                  |
| **آرتیفکت**             | اجرایی که نتیجه دارد                              | نسخه‌های مخزن شما، همراه با بهترین نسخه                            |
| **داده‌ها**             | اجرای تمام‌شده‌ای که مورد دارد                     | تقسیم داده به مجموعه‌های آموزش، اعتبارسنجی و آزمون                 |
| **کد**                  | وقتی اجرا کدی برای نمایش دارد                     | امتیازدهنده                                                       |
| **پاداش**               | اجرایی که امتیازدهنده‌اش بخش‌های پاداش تعریف می‌کند | بخش‌های پاداش و وزن‌های آن‌ها                                       |
| **لاگ‌ها**              | بیشتر اجراها                                      | لاگ اجرا                                                          |
| **مصرف و هزینه**        | وقتی وارد حساب شده‌اید                            | آنچه اجرا خرج کرد                                                 |
| **اجرای زمان‌بندی‌شده** | اجرای موفق                                        | زمان‌بندی برای اجرای دوبارهٔ بهینه‌سازی از بهترین نسخه             |
| **پیکربندی**            | همیشه                                             | پیکربندی اجرا                                                     |

> [!NOTE]
> در سطح **راهنمایی‌شده**، صفحهٔ اجرا زبانه‌های **داده‌ها**، **کد**، **لاگ‌ها** و **پیکربندی** را پنهان می‌کند. پیوند مستقیم به یکی از این زبانه‌ها همچنان آن را باز می‌کند. سطح را در **تنظیمات ← حساب** تغییر دهید.

## امتیازها

Skynet نسخه‌ها را روی نمونه‌های اعتبارسنجی انتخاب می‌کند. امتیاز نهایی را روی نمونه‌های آزمون گزارش می‌دهد. موتورها هرگز نمونه‌های آزمون را نمی‌بینند. صفحهٔ [مجموعه‌داده‌ها و تقسیم](/docs/concepts/datasets) را بخوانید.

زبانهٔ **نمای کلی** این موارد را نشان می‌دهد:

- **بهبود**: تغییر از نسخهٔ شروع تا بهترین نسخه.
- **روند پیشرفت امتیاز**: امتیاز در طول اجرا.
- **تفکیک امتیاز**: هر امتیاز، با ستون‌های **خط مبنا**، **بهینه‌شده** و **تغییر**.

تا وقتی اجرا فعال است، نمای کلی **زمان سپری‌شده**، **باقی‌مانده** و **نرخ** را هم نشان می‌دهد.

وقتی امتیازدهندهٔ شما امتیازهای نام‌دار گزارش می‌کند، نمای کلی **امتیازهای نام‌دار** را هم نشان می‌دهد.

### وقتی بهترین نسخه همان نسخهٔ شروع است

گاهی هیچ نامزدی از نسخهٔ شروع بهتر نمی‌شود. در این حالت Skynet نسخهٔ شروع را برمی‌گرداند. زبانهٔ **آرتیفکت** به شما می‌گوید که یک محافظ پسرفت اعمال شد.

اگر اجرا با رسیدن به بودجه‌اش متوقف شد، صفحهٔ اجرا به شما می‌گوید Skynet کدام نسخه را ذخیره کرد. صفحهٔ [اجراها](/docs/concepts/runs) را بخوانید.

## خروجی گرفتن از بهترین نسخه

زبانهٔ **آرتیفکت** **نسخه‌ها**ی مخزن شما را فهرست می‌کند. برای هر نسخه می‌توانید:

- نسخه را کپی کنید.
- نسخه را به‌صورت فایل دانلود کنید.
- نسخه را به‌صورت یک فایل zip از کل مخزن دانلود کنید.

می‌توانید یک نسخه را با نسخهٔ دیگری مقایسه کنید. این زبانه **بازخورد ارزیاب** را هم برای هر نسخه نشان می‌دهد.

### شاخه‌ها در یک مخزن جدید

وقتی Skynet مخزن را برای اجرا ساخته باشد، هر نامزد را به شاخهٔ خودش، `skynet/candidate-<version id>`، push می‌کند. شاخهٔ `skynet/best` همیشه به بهترین نسخه اشاره می‌کند. وقتی نسخهٔ بهتری پیدا شود، این شاخه جابه‌جا می‌شود.

## ارائهٔ بهترین نسخه

می‌توانید بهترین نسخه را از کد خودتان فراخوانی کنید. مخزن باید در ریشهٔ خود یک فایل `serve.py` داشته باشد که `serve(input)` را تعریف می‌کند:

```python tab="serve.py"
def serve(input):
    return {"label": classify(input["message"])}
```

- `input` همان dict فیلدهای ورودی از درخواست است.
- مقدار بازگشتی باید قابل تبدیل به JSON باشد. یک dict به `outputs` تبدیل می‌شود. هر مقدار دیگری به `{"output": value}` تبدیل می‌شود.
- `serve.py` می‌تواند با `llm` از ماژول کمکی `skynet` یک مدل را فراخوانی کند. اسرار اجرا را دریافت نمی‌کند.

Skynet بهترین نسخه را در همان محیط اجرای ایزولهٔ محافظت‌شدهٔ اجرا اجرا می‌کند. زبانهٔ **کاربرد** دو بخش دارد:

- یک فرم. فیلدهای ورودی را وارد کنید و برای دریافت نتیجه، **اجرا** را انتخاب کنید.
- **کد یکپارچه‌سازی** به زبان‌های cURL، Python، JavaScript و Go.

برای فراخوانی بهترین نسخه، یک توکن API در **تنظیمات ← API** بسازید. سپس یک درخواست بفرستید. سرآیند `Idempotency-Key` الزامی است:

```bash tab="cURL"
export APP_API_TOKEN=skyd_...
curl -X POST "$API_URL/serve/<optimization_id>" \
  -H "Authorization: Bearer $APP_API_TOKEN" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"message": "I was charged twice."}, "max_cost_cents": 5}'
```

```python tab="Python"
import os
import uuid
import requests

response = requests.post(
    f"{os.environ['API_URL']}/serve/<optimization_id>",
    headers={
        "Authorization": f"Bearer {os.environ['APP_API_TOKEN']}",
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={"inputs": {"message": "I was charged twice."}, "max_cost_cents": 5},
)
print(response.json()["outputs"])
```

`message` را با فیلدهای ورودی اجرای خود جایگزین کنید. **کد یکپارچه‌سازی** در زبانهٔ **کاربرد**، URL واقعی و نام فیلدها را برای شما پر می‌کند.

پاسخ شامل `outputs`، `input_fields`، `output_fields`، `model_used`، `cents_charged` و `budget` است.

> [!TIP]
> هزینهٔ هر فراخوانی جداگانه از موجودی فراخواننده کسر می‌شود. `max_cost_cents` بیشترین هزینهٔ همین یک فراخوانی را به سنت تعیین می‌کند. اگر همان `Idempotency-Key` را دوباره بفرستید، Skynet برای آن فراخوانی دوباره هزینه نمی‌گیرد.

برای احراز هویت و endpointهای دیگر، صفحهٔ [API](/docs/api) را بخوانید.

## اشتراک‌گذاری نتایج

می‌توانید یک اجرا را با دیگران به اشتراک بگذارید، یا آن را در گالری عمومی کاوش فهرست کنید. صفحهٔ [اشتراک‌گذاری و انتشار](/docs/guides/sharing) را بخوانید.
