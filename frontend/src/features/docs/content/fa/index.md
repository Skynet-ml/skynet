Skynet کدی را که از قبل دارید، یا کدی را که برای شما می‌نویسد، بهتر می‌کند. Skynet همان Optimize Anything است: هر اجرا یک مخزن را بهینه می‌کند. شما یک مخزن، مجموعه‌ای از موردها و یک امتیازدهنده به آن می‌دهید. Skynet نسخه‌های جدیدی از مخزن پیشنهاد می‌کند، هر نسخه را با امتیازدهندهٔ شما امتیاز می‌دهد و بهترین نسخه را نگه می‌دارد.

## Skynet چه چیزی را بهینه می‌کند

هر اجرا یک مخزن را بهینه می‌کند. می‌توانید به دو روش شروع کنید:

| شروع                | چه اتفاقی می‌افتد                                                                                 |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| استفاده از یک مخزن  | Skynet فایل‌های مسیرهایی را که اجازه می‌دهید، در یک مخزن GitHub که متصل می‌کنید، تغییر می‌دهد.     |
| ساخت مخزن جدید   | شما یک کار و داده می‌دهید. Skynet یک مخزن GitHub جدید در حساب شما می‌سازد و یک راه‌حل اول می‌نویسد. |

کد درون مخزن می‌تواند هر چیزی باشد: یک خط لولهٔ پرامپت، یک هارنس عامل، یک اسکریپت یا یک کتابخانه. این کد می‌تواند از هر کتابخانه‌ای استفاده کند.

همهٔ اجراها از یک قرارداد استفاده می‌کنند. امتیازدهندهٔ شما `score(repo_path, case)` را تعریف می‌کند. این تابع یک امتیاز و یک بازخورد نوشتاری برمی‌گرداند. بهینه‌ساز بازخورد را می‌خواند تا نسخهٔ بعدی را بهتر کند.

> [!NOTE]
> هر نسخه در یک محیط اجرای ایزوله (sandbox) اجرا می‌شود. عامل کدنویسی که نسخه‌ها را می‌نویسد، نمی‌تواند کد منبع امتیازدهنده یا مقدارهای مورد انتظار را ببیند.

## یک محصول، موتورهای متعدد

**Auto** پیش‌فرض همهٔ اجراهاست. این گزینه GEPA، AutoResearch، Meta-Harness، AutoSaddler و ShinkaEvolve را امتحان می‌کند و سپس GEPA را از بهترین نسخه ادامه می‌دهد. همچنین می‌توانید یک موتور را انتخاب کنید: GEPA، Best-of-N، AutoResearch، Meta-Harness، AutoSaddler یا ShinkaEvolve. [بهینه‌سازی چگونه کار می‌کند](/docs/concepts/optimization) و [موتورها](/docs/concepts/engines) را بخوانید.

## یک اجرا چگونه کار می‌کند

1. کار را توصیف می‌کنید و یک مخزن انتخاب می‌کنید یا از Skynet می‌خواهید یک مخزن بسازد.
2. موردها را می‌دهید. Skynet آن‌ها را به مجموعه‌های آموزش، اعتبارسنجی و آزمون تقسیم می‌کند.
3. یک بهینه‌ساز، مدل‌ها و یک بودجه انتخاب می‌کنید.
4. امتیازدهنده را می‌نویسید. یک بررسی راه‌اندازی آن را روی نسخهٔ شروع اجرا می‌کند.
5. Skynet بهینه‌سازی را اجرا می‌کند و نتیجه‌ها را نشان می‌دهد.

Skynet نسخه‌ها را بر اساس موردهای اعتبارسنجی انتخاب می‌کند. امتیاز نهایی را روی موردهای آزمون گزارش می‌دهد. موتورها هرگز موردهای آزمون را نمی‌بینند.
