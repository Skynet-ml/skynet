에이전트 패널은 Skynet 안에 있는 채팅 어시스턴트입니다. 에이전트는 실행, 데이터셋, 잔액을 읽을 수 있고, 실행 이름 바꾸기나 취소 같은 작업을 대신할 수 있습니다. 어떤 작업에 내 승인이 필요한지는 내가 정합니다.

## 패널 열기

패널은 앱 옆쪽에 열립니다. 패널을 최소화하면 **에이전트 열기** 라벨이 있는 알약 모양 버튼이 화면에 남습니다. 패널을 다시 열려면 이 버튼을 클릭합니다.

에이전트의 도구 목록을 보려면 **할 수 있는 작업**을 클릭합니다.

### 대화

- **새 대화**는 빈 채팅을 시작합니다.
- **지난 대화**에는 이전 채팅이 나열됩니다. 채팅을 검색하고, 고정하고, 이름을 바꾸고, 삭제할 수 있습니다.

### 메시지 보내기

메시지를 입력하고 Enter 키를 누릅니다. **음성 받아쓰기**를 클릭하고 메시지를 말할 수도 있습니다.

에이전트가 작업 중이어도 입력란을 사용할 수 있습니다.

- 지원되는 경우 **Enter**는 현재 작업에 방향을 지시합니다. 에이전트는 다음 단계에서 메시지를 읽습니다. **Tab**은 새 턴을 대기열에 추가합니다. 방향 지시를 지원하지 않으면 Enter도 대기열에 추가합니다.
- **대기 중인 메시지**에서 메시지를 편집하거나 삭제하고, 드래그하여 순서를 바꿀 수 있습니다. **방향 지시**가 가능하면 대기열의 메시지를 현재 작업으로 보냅니다.
- **확인되지 않음**으로 표시된 메시지는 회수가 확인되지 않았습니다. 명시적으로 지금 보내거나 편집하거나 삭제하세요.
- **중지**는 현재 턴을 멈추고 대기열을 일시 중지합니다. 읽지 않은 지시는 목록으로 돌아옵니다. 자동으로 시작되는 작업은 없습니다. 입력란의 **Esc**도 같은 기능입니다. 단, 메뉴가 열려 있거나 IME로 글자를 조합 중이면 중지하지 않습니다. Esc는 먼저 이 입력란의 제안이나 메뉴를 닫습니다.
- 활성 턴이 없을 때 **지금 보내기**는 일시 중지된 대기열의 첫 메시지를 보냅니다. 나머지는 순서대로 이어집니다. 턴이 정상 종료되어도 다음 메시지가 시작됩니다.
- **중지하고 지금 보내기**는 턴을 멈추고 목록 전체를 하나의 새 턴으로 보냅니다. 읽지 않은 지시가 돌아올 때까지 기다린 뒤, 대기열 메시지 앞에 놓고 빈 줄로 연결합니다. 이미 읽은 지시는 다시 보내지 않습니다. 확인되지 않은 메시지는 목록에 남고 이 턴에 포함되지 않습니다. 다른 메시지는 정상적으로 계속됩니다.
- 문서 도우미와 배포된 프로그램의 보호된 채팅은 **대기열만** 지원합니다. Enter와 Tab 모두 대기열에 추가합니다. 문서 도우미는 요청 제한에 걸리면 남은 메시지를 일시 중지합니다.

## 에이전트가 할 수 있는 일

에이전트는 다음을 읽을 수 있습니다.

- 실행, 실행 로그, 테스트 결과.
- 분석 데이터와 지갑 잔액.
- 라이브러리 데이터셋과 공개 검색 결과.
- 태깅 세션(읽기 전용).
- 샘플 데이터셋, 엔진 카탈로그, 옵티마이저 카탈로그.

에이전트는 작업도 할 수 있습니다. 안전한 작업은 다음과 같습니다.

- 실행 이름을 바꾸고 고정합니다. 여러 실행을 한 번에 고정합니다.
- 실행을 일시 중지합니다.
- 실행의 코드를 편집하고 검증합니다.
- 데이터셋을 프로파일링하고 열 역할을 설정합니다.
- 사용 가능한 모델을 찾습니다.
- 제출 마법사와 내 환경설정을 업데이트합니다.
- 샘플 데이터셋을 준비합니다.
- 폴더를 만듭니다.

파괴적인 작업은 다음과 같습니다.

- 실행 하나 또는 여러 실행을 삭제합니다.
- 실행을 제출, 취소, 복제, 재시도, 다시 시작, 처음부터 실행합니다. 여러 실행을 취소합니다.
- 폴더를 삭제, 이동, 업데이트합니다. 폴더 사이에서 실행을 이동합니다.

> [!NOTE]
> 웹 도구(검색, URL 가져오기, 사이트 크롤링)는 서버에 웹 검색 키가 설정되어 있을 때만 사용할 수 있습니다. 이 도구가 보이지 않으면 사용 중인 Skynet 인스턴스가 이 도구를 제공하지 않는 것입니다.

## 신뢰 모드

신뢰 모드는 어떤 작업에 내 승인이 필요한지 정합니다. 모드를 바꾸려면 입력창의 신뢰 토글을 클릭합니다. 토글은 세 모드를 순서대로 전환합니다.

| 모드               | 설명                                        | 안전한 작업    | 파괴적인 작업  |
| ------------------ | ------------------------------------------- | -------------- | -------------- |
| **확인**           | 모든 작업 전에 확인을 요청합니다.           | 승인 필요      | 승인 필요      |
| **자동**           | 안전한 작업은 확인 없이 수행합니다.         | 즉시 실행      | 승인 필요      |
| **제한 없음**      | 모든 작업을 확인 없이 수행합니다.           | 즉시 실행      | 즉시 실행      |

기본 모드는 **확인**입니다. 읽기 전용 도구는 승인이 필요하지 않습니다.

> [!WARNING]
> **제한 없음** 모드에서는 에이전트가 승인 없이 실행을 삭제하거나 유료 실행을 제출할 수 있습니다. 작업을 신뢰할 때만 이 모드를 사용하세요.

### 기본 모드 설정하기

1. **설정**을 엽니다.
2. **에이전트 패널** 탭을 엽니다.
3. **에이전트 신뢰 수준**에서 **먼저 묻기**, **안전한 작업에만 자동 실행**, **사전 승인 없음** 중 하나를 선택합니다.

### 작업 승인하기

작업에 승인이 필요하면 패널에 승인 카드가 표시됩니다. 카드에는 작업을 확인하는 버튼과 **취소**가 있습니다. 정확한 도구 호출을 보려면 **기술 세부 정보 표시**를 클릭합니다.

15분 안에 응답하지 않으면 에이전트는 그 작업이 거부된 것으로 처리합니다.

## 파일 첨부하기

메시지에 파일을 첨부할 수 있습니다. 파일 하나는 최대 20 MB입니다. 데이터셋은 한 번에 하나만 첨부할 수 있습니다.

에이전트를 통해 데이터셋을 업로드하려면 다음을 따릅니다.

1. CSV, JSON 또는 Excel 파일을 첨부합니다.
2. 업로드 카드를 확인합니다. 카드에 파일의 열이 표시됩니다.
3. 카드에서 열 역할을 설정한 다음 확인합니다.

에이전트가 파일을 읽을 수 없으면 카드에 "파일을 읽을 수 없습니다. CSV, JSON 또는 XLSX 파일을 사용하세요."가 표시됩니다.

파일 규칙은 [데이터셋 준비](/docs/guides/datasets)를 참고하세요.

## 모델 선택하기

입력창의 모델 메뉴에는 다음 그룹이 있습니다.

- **Auto**는 Skynet이 모델을 고르게 합니다.
- **Skynet 크레딧**은 잔액에서 비용을 내는 호스팅 모델을 사용합니다.
- **내 키 사용**은 자신의 제공업체 키로 모델을 사용합니다.

일부 모델은 추론 노력 수준을 설정할 수 있습니다. 수준은 **없음**, **최소**, **낮음**, **중간**, **높음**, **매우 높음**, **최대**입니다. **기본**은 모델의 기본 수준을 사용합니다.

새 채팅의 기본 모델을 설정하려면 **설정** > **에이전트 패널** > **기본 모델**을 엽니다.

### 비용

Skynet 크레딧으로 하는 에이전트 채팅은 잔액을 사용합니다. 잔액이 비어 있으면 패널에 "잔액이 없습니다. 에이전트와 계속 대화하려면 충전하세요."가 표시됩니다. 가격은 [예산과 결제](/docs/concepts/billing)를 읽어 보세요.

## 팁

> [!TIP]
> 실행을 바꾸기 전에 에이전트에게 실행을 설명해 달라고 요청하세요. 예: "실행 42가 실행 41보다 점수가 낮은 이유는 무엇인가요?"

> [!TIP]
> 새로운 종류의 요청을 시도할 때는 **확인** 모드를 사용하세요. 에이전트가 무엇을 할지 알게 되면 **자동**으로 바꾸세요.
