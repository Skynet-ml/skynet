Skynet, Optimize Anything है: हर रन एक रिपॉज़िटरी को ऑप्टिमाइज़ करता है। एक इंजन रिपॉज़िटरी के नए संस्करण प्रस्तावित करता है, आपका स्कोरर हर संस्करण को स्कोर करता है, और Skynet सबसे अच्छा संस्करण रखता है।

## साझा कॉन्ट्रैक्ट

हर रन में एक रिपॉज़िटरी और एक स्कोरर होता है। स्कोरर एक Python फ़ंक्शन है जिसे रिपॉज़िटरी के एक संस्करण का पाथ और एक केस मिलता है।

```python tab="scorer.py"
import importlib.util


def score(repo_path, case):
    spec = importlib.util.spec_from_file_location("serve", f"{repo_path}/serve.py")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    output = module.serve(case["input"])
    ok = output == case["expected"]
    return (1.0 if ok else 0.0), {"feedback": "Match." if ok else "No match."}
```

- `repo_path` रिपॉज़िटरी के एक संस्करण का फ़ोल्डर है, सेटअप कमांड चलने के बाद।
- `case` एक dict है। `case["input"]` में एक केस के इनपुट फ़ील्ड होते हैं। `case["expected"]` में अपेक्षित मान होता है, या `None` जब केस में कोई अपेक्षित मान नहीं है।
- `score` एक जोड़ा लौटाता है: एक संख्या, और `"feedback"` स्ट्रिंग वाला एक dict।

रिपॉज़िटरी के रूट में `def serve(input)` वाली एक `serve.py` फ़ाइल है। स्कोरर इसे कॉल कर सकता है, और रन के बाद Skynet सबसे अच्छे संस्करण को सर्व करने के लिए इसका इस्तेमाल करता है।

> [!NOTE]
> संस्करण लिखने वाला कोडिंग एजेंट स्कोरर का सोर्स, अपेक्षित मान या रन के सीक्रेट नहीं देख सकता।

पूरे स्कोरर कॉन्ट्रैक्ट के लिए [मेट्रिक और स्कोरर](/docs/concepts/scorers) पढ़ें।

## आपके कोड से मॉडल कॉल

आपकी रिपॉज़िटरी का कोड और आपका स्कोरर Skynet के मॉडल गेटवे से किसी मॉडल को कॉल कर सकते हैं। सैंडबॉक्स एनवायरनमेंट वेरिएबल में एक OpenAI-संगत एंडपॉइंट देता है:

| वेरिएबल              | इसमें क्या होता है                                              |
| -------------------- | --------------------------------------------------------------- |
| `OPENAI_BASE_URL`    | गेटवे URL। `APP_GATEWAY_URL` में भी यही मान होता है।              |
| `APP_API_KEY`        | सिर्फ़ इस रन के लिए एक टोकन। यह प्रदाता की कुंजी नहीं है।           |
| `APP_MODEL`          | भेजने के लिए मॉडल का नाम। यह रन का स्कोरर मॉडल है।                |
| `ANTHROPIC_BASE_URL` | Anthropic SDK के लिए गेटवे URL।                                  |

```python tab="pipeline.py"
import os

from openai import OpenAI

client = OpenAI(base_url=os.environ["OPENAI_BASE_URL"], api_key=os.environ["APP_API_KEY"])


def label(message):
    response = client.chat.completions.create(
        model=os.environ["APP_MODEL"],
        messages=[{"role": "user", "content": f"Label as billing, bug or other: {message}"}],
    )
    return response.choices[0].message.content
```

- Skynet की कुंजियों पर हुई कॉल रन के बजट से मापी जाती हैं।
- आपकी अपनी कुंजी (BYOK) के साथ, कॉल आपके प्रदाता की कुंजी पर जाती है। Skynet कोई मॉडल शुल्क नहीं लेता।
- गेटवे किसी भी दूसरे मॉडल के अनुरोध अस्वीकार करता है।
- रन के सीक्रेट आपके कोड और आपके स्कोरर तक एनवायरनमेंट वेरिएबल के रूप में पहुँचते हैं। वेरिएबल का नाम सीक्रेट का नाम है। Skynet आउटपुट में सीक्रेट मान छिपाता है।

सैंडबॉक्स के पास कोई दूसरा नेटवर्क एक्सेस नहीं है।

## इंजन

हर इंजन रिपॉज़िटरी पर काम करता है:

- **Auto** डिफ़ॉल्ट है। यह कई इंजन आज़माता है, फिर सबसे अच्छे संस्करण से GEPA जारी रखता है।
- **GEPA** रिफ़्लेक्शन से संस्करण विकसित करता है और एक Pareto फ्रंट रखता है।
- **Best-of-N** रिफ़्लेक्शन मॉडल से स्वतंत्र प्रस्ताव माँगता है और सबसे अच्छा रखता है।
- **AutoResearch**, **Meta-Harness**, **AutoSaddler** और **ShinkaEvolve** संस्करण प्रस्तावित करने के लिए एक कोडिंग एजेंट का इस्तेमाल करते हैं।

इंजन सिर्फ़ उन पाथ की फ़ाइलें बदलते हैं जिनकी आप अनुमति देते हैं। हर इंजन और उसकी सेटिंग्स के लिए [इंजन](/docs/concepts/engines) पढ़ें।

## Auto

विज़ार्ड में हर रन के लिए **Auto** डिफ़ॉल्ट विकल्प है।

1. Auto पाँच इंजनों से खोज करता है: GEPA, AutoResearch, Meta-Harness, AutoSaddler और ShinkaEvolve।
2. यह उनके मिले सबसे अच्छे संस्करण को चुनता है।
3. यह बजट खत्म होने तक उसी संस्करण से GEPA जारी रखता है।

Auto आपके स्कोरर का फ़ीडबैक टेक्स्ट पढ़ता है।

## शुरुआती संस्करण कहाँ से आता है

| आपकी स्थिति                              | क्या इस्तेमाल करें                                                                       |
| ---------------------------------------- | ---------------------------------------------------------------------------------------- |
| आपका कोड एक GitHub रिपॉज़िटरी में है      | **रिपॉज़िटरी इस्तेमाल करें**। आपकी चुनी ब्रांच या कमिट का कोड शुरुआत है।                    |
| आपके पास सिर्फ़ एक टास्क और डेटा है       | **नई रिपॉज़िटरी बनाएँ**। Skynet पहला समाधान लिखता है। वही शुरुआत है।                       |

> [!WARNING]
> GEPA और Auto फ़ीडबैक टेक्स्ट से सीखते हैं। अगर आपका फ़ीडबैक हमेशा एक ही स्ट्रिंग है, तो इन ऑप्टिमाइज़र के पास काम करने के लिए कम जानकारी होती है।
