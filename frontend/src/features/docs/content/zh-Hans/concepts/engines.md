引擎是为你的仓库提出新版本的搜索方法。Skynet 有六个原生引擎和 **Auto**。每个引擎都处理仓库。本页说明每个引擎做什么、何时选择它以及它有哪些设置。

如果你不知道哪个引擎适合你的任务，请先阅读[优化的工作原理](/docs/concepts/optimization)。

## 快速对比

| 引擎         | 编程智能体设置             | 最大迭代次数设置 |
| ------------ | -------------------------- | ---------------- |
| Auto         | 无                         | 无               |
| GEPA         | 无                         | 无               |
| Best-of-N    | 无                         | 无               |
| AutoResearch | 有                         | 无               |
| Meta-Harness | 有                         | 有               |
| AutoSaddler  | 有                         | 有               |
| ShinkaEvolve | 无。它有自己的编辑器设置。 | 有               |

向导会把 GEPA 和 Auto 标记为使用评分器反馈文本的优化器。

## Auto

Auto 是每次运行的默认选项。它分两个阶段工作：

1. 它用 GEPA、AutoResearch、Meta-Harness、AutoSaddler 和 ShinkaEvolve 进行探索。
2. 它从探索找到的最好版本继续运行 GEPA。

**适合在以下情况选用：** 你不知道哪个引擎适合。这是最好的起点。

## GEPA

“基于反思的演化，维护一个由多个版本组成的 Pareto 前沿。”反思模型读取每个用例的分数和反馈，并写出更好的版本。GEPA 维护一个版本前沿，其中每个版本都在某些用例上表现最好。

**适合在以下情况选用：** 你的评分器能给出具体的反馈，并且你想要一个强大的单一引擎。

## Best-of-N

“由反思模型给出相互独立的提议，保留最好的一个。”每个提议都独立于其他提议。Skynet 会在验证用例上为排名靠前的提议重新打分。

**适合在以下情况选用：** 你想要一个简单的基线，用来与其他引擎比较。

## AutoResearch

编程智能体执行多轮研究。它不断编辑、打分并保留有帮助的改动，直到预算用完。

**适合在以下情况选用：** 一个好的改动需要经过多步调查。

## Meta-Harness

编程智能体在每次迭代中提出一批候选。它会利用所有候选及其分数的完整历史。

**适合在以下情况选用：** 你想要一个能从所有过往尝试的历史中学习的智能体。使用 **每轮候选数** 来设置批次大小。

## AutoSaddler

编程智能体读取你的评分器给出的反馈，并对版本打补丁。Skynet 只保留经过新一次评分器运行确认的补丁。

**适合在以下情况选用：** 你的评分器反馈能指出明确的、局部的缺陷。

## ShinkaEvolve

“在多个并行岛屿中演化大量版本，并学习哪些模型对它们的改进最大。”它是一种针对候选种群的演化搜索，其中的变异和交叉由模型编写。

**适合在以下情况选用：** 你想要广泛探索，并且预算较大。

## 设置

### 预算

| 设置                   | 默认值 | 范围                                                          |
| ---------------------- | ------ | ------------------------------------------------------------- |
| 最大评分器运行次数     | 200    | 1 到 100000                                   |
| 停止分数               | 关闭   | 0 或更大                                                      |
| 最大迭代次数           | 关闭   | 1 到 1000。仅适用于 Meta-Harness、AutoSaddler 和 ShinkaEvolve。 |

一次评分器运行是指在一个用例上调用一次你的评分器。对起始版本和胜出版本的最终重新打分不计入 **最大评分器运行次数**。

### 编程智能体设置

这些设置适用于 AutoResearch、Meta-Harness 和 AutoSaddler。

| 设置                     | 默认值 | 范围                                              |
| ------------------------ | ------ | ------------------------------------------------- |
| 编程智能体               | Codex  | Pi、Codex、OpenCode、Prime Agent、自定义命令      |
| 每轮候选数               | 3      | 1 到 8。 |
| 每个候选的最大工具调用数 | 100    | 1 到 1000                                         |

### ShinkaEvolve 设置

| 设置                          | 默认值                                                  |
| ----------------------------- | ------------------------------------------------------- |
| 新版本的编写方式              | 单次模型调用。另一个选项是“编码代理（Pi）”。            |
| 岛屿数                        | 2（1 到 8）                                             |
| 迁移间隔                      | 10                                                      |
| 父代选择                      | 加权。其他选项：幂律、束搜索。                          |
| 差异编辑 / 完整重写 / 交叉    | 60% / 30% / 10%。三者之和必须为 100%。                  |
| 归档大小                      | 40                                                      |
| 并行评估数                    | 2                                                       |
| 并行提议数                    | 2                                                       |
