Страница запуска показывает прогресс и результаты запуска. В этом руководстве описаны вкладки страницы запуска, оценки, а также то, как экспортировать или развернуть лучшую версию.

## Вкладки страницы запуска

Страница запуска показывает только те вкладки, которые относятся к запуску. Некоторые вкладки зависят от статуса и вашего уровня опыта.

| Вкладка                       | Когда показывается                                        | Что содержит                                                      |
| ----------------------------- | --------------------------------------------------------- | ----------------------------------------------------------------- |
| **Обзор**                     | Всегда                                                    | Прогресс, оценки и история оценок                                 |
| **Использование**             | Успешный запуск, в репозитории которого есть файл `serve.py` | Форма для вызова лучшей версии и код интеграции                |
| **Артефакт**                  | Запуск, у которого есть результат                         | Версии вашего репозитория, включая лучшую                         |
| **Данные**                    | Завершённый запуск с примерами                            | Данные, разделённые на обучающую, валидационную и тестовую выборки |
| **Код**                       | Когда у запуска есть код для показа                       | Оценщик                                                           |
| **Награда**                   | Запуск, оценщик которого объявляет части награды          | Части награды и их веса                                           |
| **Логи**                      | Большинство запусков                                      | Лог запуска                                                       |
| **Использование и стоимость** | Когда вы вошли в систему                                  | Расходы запуска                                                   |
| **Запуск по расписанию**      | Успешный запуск                                           | Расписание для повторного запуска оптимизации с лучшей версии     |
| **Конфигурация**              | Всегда                                                    | Конфигурация запуска                                              |

> [!NOTE]
> На уровне **С подсказками** страница запуска скрывает вкладки **Данные**, **Код**, **Логи** и **Конфигурация**. Прямая ссылка на одну из этих вкладок всё равно её открывает. Уровень меняется в разделе **Настройки → Учётная запись**.

## Оценки

Skynet выбирает версии на валидационных примерах. Итоговую оценку он сообщает на тестовых примерах. Движки никогда не видят тестовые примеры. Прочитайте [Наборы данных и разбиение](/docs/concepts/datasets).

Вкладка **Обзор** показывает:

- **Улучшение**: изменение от исходной версии к лучшей.
- **Динамика оценки**: оценка на протяжении запуска.
- **Разбивка оценки**: каждая оценка со столбцами **Базовое значение**, **Оптимизировано** и **Изменение**.

Пока запуск активен, обзор также показывает **Прошло**, **Осталось** и **Скорость**.

Обзор также показывает **Именованные оценки**, когда ваш оценщик сообщает именованные оценки.

### Когда лучшая версия — исходная

Иногда ни один кандидат не превосходит исходную версию. Тогда Skynet возвращает исходную версию. Вкладка **Артефакт** сообщает, что сработала защита от регрессии.

Если запуск остановился по бюджету, страница запуска сообщает, какую версию сохранил Skynet. Прочитайте [Запуски](/docs/concepts/runs).

## Экспорт лучшей версии

На вкладке **Артефакт** перечислены **Версии** вашего репозитория. Для каждой версии можно:

- Скопировать версию.
- Скачать версию в виде файла.
- Скачать версию в виде zip-архива всего репозитория.

Версию можно сравнить с другой версией. Вкладка также показывает **Отзыв оценщика** для версии.

### Ветки в новом репозитории

Когда Skynet создал репозиторий для запуска, он отправляет каждого кандидата в отдельную ветку, `skynet/candidate-<version id>`. Ветка `skynet/best` всегда указывает на лучшую версию. Она перемещается, когда появляется версия лучше.

## Развёртывание лучшей версии

Лучшую версию можно вызывать из собственного кода. В корне репозитория должен быть файл `serve.py`, который определяет `serve(input)`:

```python tab="serve.py"
def serve(input):
    return {"label": classify(input["message"])}
```

- `input` — это dict входных полей из запроса.
- Возвращаемое значение должно сериализоваться в JSON. dict становится `outputs`. Любое другое значение становится `{"output": value}`.
- `serve.py` может вызвать модель через `llm` из вспомогательного модуля `skynet`. Секреты запуска он не получает.

Skynet выполняет лучшую версию в той же защищённой песочнице, что и запуск. На вкладке **Использование** есть две части:

- Форма. Введите входные поля и нажмите **Запустить**, чтобы получить результат.
- **Код интеграции** на cURL, Python, JavaScript и Go.

Чтобы вызвать лучшую версию, создайте API-токен в разделе **Настройки → API**. Затем отправьте запрос. Заголовок `Idempotency-Key` обязателен:

```bash tab="cURL"
export APP_API_TOKEN=skyd_...
curl -X POST "$API_URL/serve/<optimization_id>" \
  -H "Authorization: Bearer $APP_API_TOKEN" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"message": "I was charged twice."}, "max_cost_cents": 5}'
```

```python tab="Python"
import os
import uuid
import requests

response = requests.post(
    f"{os.environ['API_URL']}/serve/<optimization_id>",
    headers={
        "Authorization": f"Bearer {os.environ['APP_API_TOKEN']}",
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={"inputs": {"message": "I was charged twice."}, "max_cost_cents": 5},
)
print(response.json()["outputs"])
```

Замените `message` на входные поля вашего запуска. **Код интеграции** на вкладке **Использование** подставляет реальный URL и имена полей за вас.

Ответ содержит `outputs`, `input_fields`, `output_fields`, `model_used`, `cents_charged` и `budget`.

> [!TIP]
> Каждый вызов оплачивается отдельно, с баланса того, кто вызывает. `max_cost_cents` задаёт максимальную стоимость одного вызова в центах. Если отправить тот же `Idempotency-Key` ещё раз, Skynet не списывает плату за вызов повторно.

Аутентификация и другие эндпоинты описаны в разделе [API](/docs/api).
