Skynet — это Optimize Anything: каждый запуск оптимизирует репозиторий. Движок предлагает новые версии репозитория, ваш оценщик оценивает каждую версию, а Skynet сохраняет лучшую.

## Общий контракт

У каждого запуска есть репозиторий и оценщик. Оценщик — это функция Python, которая получает путь к одной версии репозитория и один пример.

```python tab="scorer.py"
import importlib.util


def score(repo_path, case):
    spec = importlib.util.spec_from_file_location("serve", f"{repo_path}/serve.py")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    output = module.serve(case["input"])
    ok = output == case["expected"]
    return (1.0 if ok else 0.0), {"feedback": "Match." if ok else "No match."}
```

- `repo_path` — папка одной версии репозитория после выполнения команды настройки.
- `case` — это dict. `case["input"]` содержит входные поля одного примера. `case["expected"]` содержит ожидаемое значение или `None`, если у примера его нет.
- `score` возвращает пару: число и dict со строкой `"feedback"`.

В корне репозитория есть файл `serve.py` с `def serve(input)`. Оценщик может его вызывать, а Skynet после запуска обслуживает через него лучшую версию.

> [!NOTE]
> Агент для кода, который пишет версии, не видит исходный код оценщика, ожидаемые значения и секреты запуска.

Полный контракт оценщика описан в разделе [Метрики и оценщики](/docs/concepts/scorers).

## Вызовы моделей из вашего кода

Код вашего репозитория и ваш оценщик могут вызывать модель через шлюз моделей Skynet. Песочница даёт OpenAI-совместимую точку доступа в переменных окружения:

| Переменная           | Что содержит                                                   |
| -------------------- | -------------------------------------------------------------- |
| `OPENAI_BASE_URL`    | URL шлюза. `APP_GATEWAY_URL` содержит то же значение.          |
| `APP_API_KEY`        | Токен только для этого запуска. Это не ключ провайдера.        |
| `APP_MODEL`          | Имя модели для запроса. Это модель оценщика этого запуска.     |
| `ANTHROPIC_BASE_URL` | URL шлюза для SDK Anthropic.                                   |

```python tab="pipeline.py"
import os

from openai import OpenAI

client = OpenAI(base_url=os.environ["OPENAI_BASE_URL"], api_key=os.environ["APP_API_KEY"])


def label(message):
    response = client.chat.completions.create(
        model=os.environ["APP_MODEL"],
        messages=[{"role": "user", "content": f"Label as billing, bug or other: {message}"}],
    )
    return response.choices[0].message.content
```

- Вызовы на ключах Skynet учитываются в бюджете запуска.
- С вашим собственным ключом (BYOK) вызов идёт на ключ вашего провайдера. Skynet не взимает плату за модель.
- Шлюз отклоняет запросы к любой другой модели.
- Секреты запуска попадают в ваш код и оценщик как переменные окружения. Имя переменной совпадает с именем секрета. Skynet скрывает значения секретов в выводе.

Другого доступа к сети у песочницы нет.

## Движки

Все движки работают с репозиториями:

- **Auto** — вариант по умолчанию. Он пробует несколько движков, затем продолжает GEPA с лучшей версии.
- **GEPA** развивает версии через рефлексию и поддерживает фронт Парето.
- **Best-of-N** запрашивает у модели рефлексии независимые предложения и сохраняет лучшее.
- **AutoResearch**, **Meta-Harness**, **AutoSaddler** и **ShinkaEvolve** используют агента для кода, чтобы предлагать версии.

Движки меняют только файлы в путях, которые вы разрешили. Каждый движок и его настройки описаны в разделе [Движки](/docs/concepts/engines).

## Auto

**Auto** — вариант по умолчанию в мастере, для каждого запуска.

1. Auto исследует с помощью пяти движков: GEPA, AutoResearch, Meta-Harness, AutoSaddler и ShinkaEvolve.
2. Он выбирает лучшую версию, которую они нашли.
3. Он продолжает GEPA с этой версии, пока не закончится бюджет.

Auto читает текст обратной связи вашего оценщика.

## Откуда берётся исходная версия

| Ваша ситуация                        | Что использовать                                                                       |
| ------------------------------------ | -------------------------------------------------------------------------------------- |
| У вас есть код в репозитории GitHub  | **Использовать репозиторий**. Код в выбранной ветке или коммите — это исходная версия. |
| У вас есть только задача и данные    | **Создать новый репозиторий**. Skynet пишет первое решение. Это исходная версия.       |

> [!WARNING]
> GEPA и Auto учатся на тексте обратной связи. Если обратная связь всегда одна и та же строка, у этих оптимизаторов меньше информации для работы.
