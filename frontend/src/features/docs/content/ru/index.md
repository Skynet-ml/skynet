Skynet улучшает код, который у вас уже есть, или код, который он пишет для вас. Skynet — это Optimize Anything: каждый запуск оптимизирует репозиторий. Вы задаёте репозиторий, набор примеров и оценщик. Skynet предлагает новые версии репозитория, оценивает каждую вашим оценщиком и сохраняет лучшую версию.

## Что оптимизирует Skynet

Каждый запуск оптимизирует репозиторий. Начать можно двумя способами:

| Начало                       | Что происходит                                                                                     |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| Использовать репозиторий     | Skynet меняет файлы в разрешённых вами путях в репозитории GitHub, который вы подключаете.          |
| Создать новый репозиторий    | Вы задаёте задачу и данные. Skynet создаёт новый репозиторий GitHub в вашем аккаунте и пишет первое решение. |

Код в репозитории может быть любым: приложение, сервис, скрипт или библиотека. Он может использовать любую библиотеку.

Все запуски используют один и тот же контракт. Ваш оценщик определяет `score(repo_path, case)`. Он возвращает оценку и текстовую обратную связь. Оптимизатор читает обратную связь, чтобы сделать следующую версию лучше.

> [!NOTE]
> Каждая версия выполняется в песочнице. Агент для кода, который пишет версии, не видит исходный код оценщика и ожидаемые значения.

## Один продукт, много движков

**Auto** — вариант по умолчанию для каждого запуска. Он пробует GEPA, AutoResearch, Meta-Harness, AutoSaddler и ShinkaEvolve, затем продолжает GEPA с лучшей версии. Вы также можете выбрать один движок: GEPA, Best-of-N, AutoResearch, Meta-Harness, AutoSaddler или ShinkaEvolve. Прочитайте [Как работает оптимизация](/docs/concepts/optimization) и [Движки](/docs/concepts/engines).

## Как проходит запуск

1. Вы описываете задачу и выбираете репозиторий или просите Skynet создать его.
2. Вы передаёте примеры. Skynet делит их на обучающую, валидационную и тестовую выборки.
3. Вы выбираете оптимизатор, модели и бюджет.
4. Вы пишете оценщик. Проверка настройки запускает его на исходной версии.
5. Skynet выполняет оптимизацию и показывает результаты.

Skynet выбирает версии на валидационных примерах. Итоговую оценку он сообщает на тестовых примерах. Движки никогда не видят тестовые примеры.
