実行ページには、実行の進捗と結果が表示されます。このガイドでは、実行ページのタブ、スコア、最良のバージョンをエクスポートまたは提供する方法を説明します。

## 実行ページのタブ

実行ページには、その実行に該当するタブだけが表示されます。一部のタブは、ステータスと経験レベルによって表示が変わります。

| タブ                 | 表示される条件                                               | 内容                                                                     |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------ |
| **概要**             | 常に                                                         | 進捗、スコア、スコアの履歴                                               |
| **使用状況**         | リポジトリに `serve.py` ファイルがある、成功した実行         | 最良のバージョンを呼び出すフォームと、連携コード                         |
| **成果物**           | 結果がある実行                                               | リポジトリのバージョンと、最良のバージョン                               |
| **データ**           | ケースがある、完了した実行                                   | 学習・検証・テストのセットへのデータの分割                               |
| **コード**           | 実行に表示するコードがあるとき                               | スコアラー                                                               |
| **報酬**             | スコアラーが報酬パーツを宣言している実行                     | 報酬の構成要素とその重み                                                 |
| **ログ**             | ほとんどの実行                                               | 実行ログ                                                                 |
| **使用量とコスト**   | サインインしているとき                                       | 実行が支出した金額                                                       |
| **スケジュール実行** | 成功した実行                                                 | 最良のバージョンから最適化を再度実行するスケジュール                     |
| **設定**             | 常に                                                         | 実行の設定                                                               |

> [!NOTE]
> **ガイド付き** レベルでは、実行ページで **データ**、**コード**、**ログ**、**設定** のタブが非表示になります。これらのタブへの直接リンクからは、引き続き開くことができます。レベルは **設定 → アカウント** で変更します。

## スコア

Skynet は検証ケースでバージョンを選びます。最終スコアはテストケースで報告します。エンジンがテストケースを見ることはありません。[データセットと分割](/docs/concepts/datasets) をお読みください。

**概要** タブには次の項目が表示されます。

- **改善**: 開始バージョンから最良のバージョンへの変化。
- **スコアの推移**: 実行を通じたスコア。
- **スコアの内訳**: 各スコアと、**ベースライン**、**最適化後**、**変化** の列。

実行がアクティブな間は、概要に **経過時間**、**残り時間**、**レート** も表示されます。

スコアラーが名前付きスコアを報告すると、概要に **名前付きスコア** も表示されます。

### 最良のバージョンが開始バージョンである場合

どの候補も開始バージョンを上回らないことがあります。その場合、Skynet は開始バージョンを返します。**成果物** タブには、リグレッションガードが適用されたことが表示されます。

実行が予算に達して停止した場合、実行ページには Skynet がどのバージョンを保存したかが表示されます。[実行](/docs/concepts/runs) をお読みください。

## 最良のバージョンをエクスポートする

**成果物** タブには、リポジトリの **バージョン** が一覧表示されます。各バージョンについて、次のことができます。

- バージョンをコピーする。
- バージョンをファイルとしてダウンロードする。
- バージョンをリポジトリ全体の zip としてダウンロードする。

バージョンを別のバージョンと比較できます。このタブには、バージョンの **スコアラーのフィードバック** も表示されます。

### 新しいリポジトリのブランチ

Skynet が実行のためにリポジトリを作成した場合、各候補をそれぞれのブランチ `skynet/candidate-<version id>` にプッシュします。`skynet/best` ブランチは常に最も良いバージョンを指します。より良いバージョンが現れると、このブランチは移動します。

## 最良のバージョンを提供する

最良のバージョンを、自分のコードから呼び出せます。リポジトリのルートには、`serve(input)` を定義する `serve.py` ファイルが必要です。

```python tab="serve.py"
def serve(input):
    return {"label": classify(input["message"])}
```

- `input` は、リクエストの入力フィールドの dict です。
- 戻り値は JSON にシリアライズできる必要があります。dict は `outputs` になります。それ以外の値は `{"output": value}` になります。
- `serve.py` は、ヘルパーモジュール `skynet` の `llm` でモデルを呼び出せます。実行のシークレットは受け取りません。

Skynet は、実行と同じ保護されたサンドボックスで最良のバージョンを実行します。**使用状況** タブには 2 つの部分があります。

- フォーム。入力フィールドを入力し、**実行** を選択すると結果が得られます。
- cURL、Python、JavaScript、Go の **連携コード**。

最良のバージョンを呼び出すには、**設定 → API** で API トークンを作成します。次に、リクエストを送信します。`Idempotency-Key` ヘッダーは必須です。

```bash tab="cURL"
export APP_API_TOKEN=skyd_...
curl -X POST "$API_URL/serve/<optimization_id>" \
  -H "Authorization: Bearer $APP_API_TOKEN" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"message": "I was charged twice."}, "max_cost_cents": 5}'
```

```python tab="Python"
import os
import uuid
import requests

response = requests.post(
    f"{os.environ['API_URL']}/serve/<optimization_id>",
    headers={
        "Authorization": f"Bearer {os.environ['APP_API_TOKEN']}",
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={"inputs": {"message": "I was charged twice."}, "max_cost_cents": 5},
)
print(response.json()["outputs"])
```

`message` は、実行の入力フィールドに置き換えてください。**使用状況** タブの **連携コード** には、実際の URL とフィールド名が入力されています。

レスポンスには、`outputs`、`input_fields`、`output_fields`、`model_used`、`cents_charged`、`budget` が含まれます。

> [!TIP]
> 各呼び出しは個別に、呼び出し元の残高から請求されます。`max_cost_cents` は、この 1 回の呼び出しにかけられる最大コストをセント単位で設定します。同じ `Idempotency-Key` を再度送信しても、Skynet はその呼び出しを再度請求しません。

認証とその他のエンドポイントについては、[API](/docs/api) をお読みください。
