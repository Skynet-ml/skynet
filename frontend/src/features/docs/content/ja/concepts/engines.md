エンジンは、リポジトリの新しいバージョンを提案する探索手法です。Skynet には 6 つのネイティブエンジンと **Auto** があります。すべてのエンジンがリポジトリで動作します。このページでは、それぞれの動作、選ぶタイミング、設定を説明します。

どのエンジンがタスクに合うかわからない場合は、まず [最適化の仕組み](/docs/concepts/optimization) をお読みください。

## 簡単な比較

| エンジン     | コーディングエージェントの設定         | 最大反復回数の設定 |
| ------------ | -------------------------------------- | ------------------ |
| Auto         | なし                                   | なし               |
| GEPA         | なし                                   | なし               |
| Best-of-N    | なし                                   | なし               |
| AutoResearch | あり                                   | なし               |
| Meta-Harness | あり                                   | あり               |
| AutoSaddler  | あり                                   | あり               |
| ShinkaEvolve | なし。独自のエディター設定があります。 | あり               |

ウィザードでは、GEPA と Auto が、スコアラーからのフィードバックの文章を使うオプティマイザーとして示されます。

## Auto

Auto はすべての実行の既定の選択です。2 つのフェーズで動作します。

1. GEPA、AutoResearch、Meta-Harness、AutoSaddler、ShinkaEvolve で探索します。
2. 探索で見つかった最も良いバージョンから GEPA を続けます。

**選ぶべき場面:** どのエンジンが合うかわからないとき。最初に試すのに最適です。

## GEPA

「パレートフロントを持つ、バージョンのリフレクティブな進化。」リフレクションモデルが各ケースのスコアとフィードバックを読み、より良いバージョンを書きます。GEPA は、それぞれが一部のケースで最良となるバージョンのフロントを維持します。

**選ぶべき場面:** スコアラーが具体的なフィードバックを返し、強力な単一エンジンを使いたいとき。

## Best-of-N

「リフレクションモデルからの独立した提案。最良のものを残す。」各提案は他の提案から独立しています。Skynet は上位の提案を検証ケースで再採点します。

**選ぶべき場面:** 他のエンジンと比較するためのシンプルなベースラインがほしいとき。

## AutoResearch

コーディングエージェントが研究ラウンドを実行します。予算がなくなるまで、編集し、採点し、効果のあるものを残します。

**選ぶべき場面:** 良い変更に何段階かの調査が必要なとき。

## Meta-Harness

コーディングエージェントが、反復ごとに候補のバッチを提案します。候補とスコアの全履歴を使います。

**選ぶべき場面:** これまでのすべての試行の履歴から学習するエージェントを使いたいとき。バッチサイズは **反復ごとの候補数** で設定します。

## AutoSaddler

コーディングエージェントがスコアラーからのフィードバックを読み、バージョンにパッチを当てます。Skynet は、新しいスコアラー実行で効果が確認されたパッチだけを残します。

**選ぶべき場面:** スコアラーのフィードバックが、明確で局所的な欠陥を指摘しているとき。

## ShinkaEvolve

「並列の島で多数のバージョンを進化させ、どのモデルが最も改善するかを学習する。」候補の集団に対する進化的探索で、モデルが書く突然変異と交叉を使います。

**選ぶべき場面:** 幅広く探索したく、予算に余裕があるとき。

## 設定

### 予算

| 設定                       | 既定値 | 範囲                                                            |
| -------------------------- | ------ | --------------------------------------------------------------- |
| 最大スコアラー実行回数     | 200    | 1〜100000                                       |
| 停止スコア                 | オフ   | 0 以上                                                          |
| 最大反復回数               | オフ   | 1〜1000。Meta-Harness、AutoSaddler、ShinkaEvolve のみ。         |

1 回のスコアラー実行は、1 つのケースに対するスコアラーの 1 回の呼び出しです。開始バージョンと勝者の最終的な再採点は、**最大スコアラー実行回数** には含まれません。

### コーディングエージェントの設定

これらの設定は、AutoResearch、Meta-Harness、AutoSaddler に適用されます。

| 設定                                 | 既定値 | 範囲                                                     |
| ------------------------------------ | ------ | -------------------------------------------------------- |
| コーディングエージェント             | Codex  | Pi、Codex、OpenCode、OpenCode V2、Prime Agent、Aider、OpenHands、OpenHands SDK、Antigravity SDK、Goose、Hermes Agent、eve、DeerFlow、Cline、Code Puppy、カスタムコマンド       |
| 反復ごとの候補数                     | 3      | 1〜8。 |
| 候補あたりの最大ツール呼び出し数     | 100    | 1〜1000                                                  |

### ShinkaEvolve の設定

| 設定                                     | 既定値                                                                        |
| ---------------------------------------- | ----------------------------------------------------------------------------- |
| 新しいバージョンの作成方法               | 単一のモデル呼び出し。もう 1 つの選択肢は「コーディングエージェント（Pi）」です。 |
| 島                                       | 2（1〜8）                                                                     |
| 移住間隔                                 | 10                                                                            |
| 親選択                                   | 重み付き。他の選択肢: べき乗則、ビームサーチ。                                |
| 差分編集 / 全体の書き直し / 交叉         | 60% / 30% / 10%。合計が 100% になる必要があります。                           |
| アーカイブサイズ                         | 40                                                                            |
| 並列評価数                               | 2                                                                             |
| 並列提案数                               | 2                                                                             |
