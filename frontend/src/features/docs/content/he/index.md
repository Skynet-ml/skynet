Skynet משפר קוד שכבר יש לך, או קוד שהוא כותב בשבילך. ‏Skynet הוא Optimize Anything: כל ריצה מייעלת מאגר קוד. נותנים לו מאגר, קבוצת מקרים ופונקציית ניקוד. ‏Skynet מציע גרסאות חדשות של המאגר, נותן ציון לכל אחת מהן בעזרת פונקציית הניקוד שלך, ושומר את הגרסה הטובה ביותר.

## מה Skynet משפר

כל ריצה מייעלת מאגר קוד. אפשר להתחיל בשתי דרכים:

| התחלה                 | מה קורה                                                                                  |
| --------------------- | ---------------------------------------------------------------------------------------- |
| שימוש במאגר קיים       | ‏Skynet משנה את הקבצים בנתיבים שמותר לו לשנות, במאגר GitHub שחיברת.                     |
| יצירת מאגר חדש         | נותנים משימה ונתונים. ‏Skynet יוצר מאגר GitHub חדש בחשבון שלך וכותב פתרון ראשון.          |

הקוד במאגר יכול להיות כל דבר: צינור פרומפטים, מעטפת לסוכן, סקריפט או ספרייה. הוא יכול להשתמש בכל ספרייה.

כל ריצה משתמשת באותו חוזה. פונקציית הניקוד שלך מגדירה `score(repo_path, case)`. היא מחזירה ציון ומשוב כתוב. האופטימייזר קורא את המשוב כדי לשפר את הגרסה הבאה.

> [!NOTE]
> כל גרסה רצה ב-sandbox. סוכן הקוד שכותב את הגרסאות לא רואה את קוד המקור של פונקציית הניקוד ולא את הערכים הצפויים.

## מוצר אחד, הרבה מנועים

‏**Auto** הוא ברירת המחדל לכל ריצה. הוא מנסה את GEPA,‏ AutoResearch,‏ Meta-Harness,‏ AutoSaddler ו-ShinkaEvolve, ואז ממשיך עם GEPA מהגרסה הטובה ביותר. אפשר גם לבחור מנוע אחד: GEPA,‏ Best-of-N,‏ AutoResearch,‏ Meta-Harness,‏ AutoSaddler או ShinkaEvolve. קרא/י את [איך האופטימיזציה עובדת](/docs/concepts/optimization) ואת [מנועים](/docs/concepts/engines).

## איך ריצה עובדת

1. מתארים את המשימה, ובוחרים מאגר או מבקשים מ-Skynet ליצור מאגר.
2. נותנים את המקרים. Skynet מחלק אותם לקבוצות אימון, אימות ובדיקה.
3. בוחרים אופטימייזר, מודלים ותקציב.
4. כותבים את פונקציית הניקוד. בדיקת הגדרות מריצה אותה על גרסת ההתחלה.
5. Skynet מריץ את האופטימיזציה ומציג את התוצאות.

Skynet בוחר גרסאות לפי מקרי האימות. הוא מדווח על הציון הסופי לפי מקרי הבדיקה. המנועים אף פעם לא רואים את מקרי הבדיקה.
