تعرض صفحة التشغيل تقدّم التشغيل ونتائجه. يشرح هذا الدليل التبويبات في صفحة التشغيل، والدرجات، وكيف تصدّر أفضل إصدار أو تقدّمه كخدمة.

## التبويبات في صفحة التشغيل

تعرض صفحة التشغيل فقط التبويبات التي تنطبق على التشغيل. تعتمد بعض التبويبات على الحالة ومستوى خبرتك.

| التبويب                | متى يظهر                                          | ما يحتويه                                                       |
| ---------------------- | ------------------------------------------------- | --------------------------------------------------------------- |
| **نظرة عامة**          | دائمًا                                            | التقدّم والدرجات وسجل الدرجات                                   |
| **الاستخدام**          | تشغيل ناجح في مستودعه ملف `serve.py`              | نموذج لاستدعاء أفضل إصدار، وكود التكامل                         |
| **المخرج**             | تشغيل له نتيجة                                    | إصدارات مستودعك، مع أفضل إصدار                                  |
| **البيانات**           | تشغيل منتهٍ له حالات                              | البيانات مقسّمة إلى مجموعات التدريب والتحقّق والاختبار          |
| **الكود**              | عندما يكون للتشغيل كود يمكن عرضه                  | المُقيِّم                                                        |
| **المكافأة**           | تشغيل يعلن مُقيِّمه أجزاء مكافأة                   | أجزاء المكافأة وأوزانها                                         |
| **السجلات**            | معظم التشغيلات                                    | سجل التشغيل                                                     |
| **الاستخدام والتكلفة** | عندما تكون مسجّل الدخول                           | ما أنفقه التشغيل                                                |
| **تشغيل مجدول**        | تشغيل ناجح                                        | جدول لتشغيل التحسين مرة أخرى من أفضل إصدار                      |
| **الإعدادات**          | دائمًا                                            | إعدادات التشغيل                                                 |

> [!NOTE]
> في المستوى **الموجَّه**، تخفي صفحة التشغيل تبويبات **البيانات** و**الكود** و**السجلات** و**الإعدادات**. الرابط المباشر إلى أحد هذه التبويبات يفتحه مع ذلك. غيّر المستوى في **الإعدادات ← الحساب**.

## الدرجات

يختار Skynet الإصدارات على حالات التحقّق. ويبلّغ عن الدرجة النهائية على حالات الاختبار. لا ترى المحرّكات حالات الاختبار أبدًا. اقرأ [مجموعات البيانات والتقسيمات](/docs/concepts/datasets).

يعرض تبويب **نظرة عامة**:

- **التحسُّن**: التغيير من إصدار البداية إلى أفضل إصدار.
- **تطوّر النتيجة**: الدرجة على مدار التشغيل.
- **تفصيل النتيجة**: كل درجة، مع الأعمدة **الأساس** و**مُحسَّن** و**التغيير**.

ما دام التشغيل نشطًا، تعرض النظرة العامة أيضًا **المنقضي** و**المتبقي** و**المعدّل**.

تعرض النظرة العامة أيضًا **الدرجات المسماة** عندما يبلّغ مُقيِّمك عن درجات مسمّاة.

### عندما يكون أفضل إصدار هو إصدار البداية

أحيانًا لا يتفوّق أي مرشّح على إصدار البداية. عندها يُرجع Skynet إصدار البداية. يخبرك تبويب **المخرج** بأنه طُبّقت حماية من التراجع.

إذا توقف التشغيل عند ميزانيته، تخبرك صفحة التشغيل بالإصدار الذي حفظه Skynet. اقرأ [عمليات التشغيل](/docs/concepts/runs).

## تصدير أفضل إصدار

يسرد تبويب **المخرج** **الإصدارات** الخاصة بمستودعك. لكل إصدار يمكنك:

- نسخ الإصدار.
- تنزيل الإصدار كملف.
- تنزيل الإصدار كملف zip للمستودع كاملًا.

يمكنك مقارنة إصدار بإصدار آخر. يعرض التبويب أيضًا **ملاحظات المُقيِّم** لكل إصدار.

### الفروع في مستودع جديد

عندما ينشئ Skynet المستودع للتشغيل، يدفع كل مرشّح إلى فرع خاص به، `skynet/candidate-<version id>`. يشير الفرع `skynet/best` دائمًا إلى أفضل إصدار. ويتحرّك عندما يظهر إصدار أفضل.

## تقديم أفضل إصدار كخدمة

يمكنك استدعاء أفضل إصدار من الكود الخاص بك. يجب أن يكون في جذر المستودع ملف `serve.py` يعرّف `serve(input)`:

```python tab="serve.py"
def serve(input):
    return {"label": classify(input["message"])}
```

- `input` هو dict حقول الإدخال من الطلب.
- يجب أن تكون قيمة الإرجاع قابلة للتحويل إلى JSON. يصبح الـ dict هو `outputs`. وتصبح أي قيمة أخرى `{"output": value}`.
- يمكن لـ `serve.py` استدعاء نموذج عبر `llm` من الوحدة المساعدة `skynet`. لا يحصل على أسرار التشغيل.

يشغّل Skynet أفضل إصدار في البيئة المعزولة المحمية نفسها التي يعمل فيها التشغيل. لتبويب **الاستخدام** جزءان:

- نموذج إدخال. أدخل حقول الإدخال واختر **تشغيل** للحصول على نتيجة.
- **كود التكامل** بلغات cURL وPython وJavaScript وGo.

لاستدعاء أفضل إصدار، أنشئ رمز API في **الإعدادات ← API**. ثم أرسل طلبًا. الترويسة `Idempotency-Key` مطلوبة:

```bash tab="cURL"
export APP_API_TOKEN=skyd_...
curl -X POST "$API_URL/serve/<optimization_id>" \
  -H "Authorization: Bearer $APP_API_TOKEN" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"message": "I was charged twice."}, "max_cost_cents": 5}'
```

```python tab="Python"
import os
import uuid
import requests

response = requests.post(
    f"{os.environ['API_URL']}/serve/<optimization_id>",
    headers={
        "Authorization": f"Bearer {os.environ['APP_API_TOKEN']}",
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={"inputs": {"message": "I was charged twice."}, "max_cost_cents": 5},
)
print(response.json()["outputs"])
```

استبدل `message` بحقول الإدخال في تشغيلك. يملأ **كود التكامل** في تبويب **الاستخدام** عنوان URL الحقيقي وأسماء الحقول لك.

تحتوي الاستجابة على `outputs` و`input_fields` و`output_fields` و`model_used` و`cents_charged` و`budget`.

> [!TIP]
> يُحاسَب كل استدعاء وحده، من رصيد الجهة المستدعية. يعيّن `max_cost_cents` أقصى تكلفة لهذا الاستدعاء الواحد، بالسنتات. إذا أرسلت `Idempotency-Key` نفسه مرة أخرى، فلن يحاسب Skynet على الاستدعاء مرة أخرى.

اقرأ [API](/docs/api) للمصادقة ونقاط النهاية الأخرى.
